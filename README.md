# Hidro Center — Business Website

Hidro Center is a business website project created to present a company's services and make information easier for visitors to find.

## Overview

The project focuses on providing a clear online presence for the business through a simple website interface.

## Built With

- HTML

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/MauMar05/Hidro-Center.git
   ```

2. Open the project folder.
3. Open the main HTML file in your web browser.

## Project Purpose

This project demonstrates the creation of a business website using front-end web technology.
